## Summary

The Cultural Peace repo is a static clone of CulturalPeace.org, originally hosted on Squarespace. The site is deployed from the `docs/` folder to GitHub Pages at culturalpeace.org. A Node.js pipeline scrapes, cleans, and verifies the site. (CLAUDE.md:148–203)

## Pipeline Overview

Four-stage pipeline, each a separate `.mjs` script:

```
Squarespace XML Export
  ↓ parse-xml.mjs
  xml_data/     (gitignored)
  ↓ scrape.mjs  (Puppeteer, full JS rendering)
  culturalpeace_clone/   (gitignored)
  ↓ clean-for-github.mjs
  docs/         → GitHub Pages deployment
  ↓ verify.mjs  (pixelmatch/resemblejs visual regression)
```

(CLAUDE.md:155–162, 179–197)

## Directory Structure

```
/
├── docs/                     — GitHub Pages deployment source
│   ├── index.html            — Homepage
│   ├── assets/               — CSS, images, JS
│   ├── sitemap.xml           — Auto-generated by clean script
│   ├── robots.txt            — Auto-generated
│   ├── 404.html              — Auto-generated
│   └── CNAME                 — Custom domain: culturalpeace.org
├── culturalpeace_clone/      — Raw scrape output (gitignored)
├── xml_data/                 — Parsed XML data (gitignored)
├── Backport/                 — Separate email collection service (own package.json, unrelated)
├── Squarespace-Wordpress-Export-07-26-2025a.xml
├── Squarespace-Wordpress-Export-07-26-2025b.xml
└── scripts: parse-xml.mjs, scrape.mjs, clean-for-github.mjs, verify.mjs, etc.
```

(CLAUDE.md:171–183, directory listing)

## Key Scripts

| Script | Stage | Purpose |
|--------|-------|---------|
| `parse-xml.mjs` | 1 | Parse Squarespace XML export → `xml_data/` |
| `scrape.mjs` | 2 | Puppeteer crawler: JS rendering, asset localization, removes tracking scripts |
| `clean-for-github.mjs` | 3 | Remove Squarespace classes, fix relative paths, minify HTML, generate sitemap/robots/404 |
| `verify.mjs` | 4 | Visual regression via pixelmatch/resemblejs |

(CLAUDE.md:179–197)

## Key Dependencies

- **puppeteer** — headless browser scraping
- **cheerio** — HTML parsing
- **html-minifier-terser** — HTML minification (post-processing)
- **pixelmatch / resemblejs** — visual comparison

(CLAUDE.md:198–203)

## Deployment

GitHub Pages from `docs/` folder on `main` branch. CNAME in `docs/` configures culturalpeace.org. (CLAUDE.md:201–203)

## Local Dev

```bash
cd docs && python -m http.server 8000
# or
npx serve docs
```

(CLAUDE.md:163–168)
